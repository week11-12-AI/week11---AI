# Phase 1 구현 현황

이 문서는 구현한 기능과 남은 작업, 검증 결과를 기록한다. 목표와 설계 결정은 [Phase 1 설계](phase1-design.md)를 참고한다.

## 구현 완료

- [x] DOM의 요소·텍스트·속성과 `data-key`를 VDOM으로 변환
- [x] VDOM을 DOM으로 렌더링하고 지원하는 입력 요소의 현재 상태 보존
- [x] Diff에서 텍스트·속성·폼 속성 변경, 요소 추가·삭제·교체 감지
- [x] Diff에서 key 기반 형제 대응과 삽입·삭제·이동 목록 생성
- [x] 같은 부모의 중복 key를 Diff에서 오류로 감지
- [x] 변경 목록을 실제 DOM에 반영하는 Patch. 변경 전 경로의 DOM 참조를 먼저 찾고 추가·삭제·교체·이동·속성·텍스트·폼 상태를 반영
- [x] 제목 변경을 입력하고 Patch를 적용하는 임시 데모 (2026-11-10 전체 편집 화면으로 대체)

## 다음 작업

Phase 1의 기록된 미구현 기능은 완료했다. 다음 개발 단계는 Phase 2의 컴포넌트·State·Hook이다. Phase 2 구현은 이번 작업 범위에 포함하지 않았다.

## 현재 지원 범위

- 히스토리는 메모리에서 관리하며 새로고침하면 초기화된다.
- 추가 태그는 p, h3, div, span, strong, button, input, textarea, ul, li다. 새 요소는 선택 요소 뒤에 추가하고, 선택이 없으면 루트 마지막에 추가한다.
- 속성 도구는 class, title, id, placeholder, aria-label, value, checked, disabled, type을 지원한다. input type 변경은 text·checkbox로 제한한다.
- 붙여넣기는 일반 텍스트만 허용한다. Enter로 브라우저가 key를 복제한 경우 충돌 UI로 해결한다.
- 단일 select·option은 엔진에서 지원하지만 추가 UI는 제공하지 않는다. 다중 select, 파일 선택값 복원, 이벤트 핸들러 편집은 지원하지 않는다.
- 자세한 실행·시연 순서는 프로젝트 README에 기록했다.
