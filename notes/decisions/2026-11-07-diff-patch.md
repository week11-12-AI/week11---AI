# Phase 1 Diff와 Patch의 분리

- 날짜 및 상태 — 2026-11-07, 확정
- 결정 — Diff가 이전 Virtual DOM과 새 Virtual DOM의 변경 목록을 만들고, Patch가 그 목록을 실제 DOM에 적용한다.
- 이유 — 각 단계의 결과를 따로 확인하고 설명하기 쉽도록 한다.
- 검토한 선택지 — 변경 목록을 만든 뒤 적용, 비교하면서 실제 DOM을 바로 수정
- 고려 사항 — 변경 목록의 형식과 적용 순서를 정해야 한다.
- 추가 결정 — 변경 대상은 Virtual DOM의 위치 경로로 표시한다. 이유 미기록.
- 고려 사항 — Patch는 경로로 DOM 노드를 찾으며 여러 형제 노드를 추가·삭제할 때 적용 순서를 보장해야 한다.
- 추가 결정 — 변경 대상 경로는 변경 전 트리를 기준으로 하고, Patch는 구조 변경 전에 기존 대상 DOM 노드를 먼저 찾는다. 이유 미기록.
- 미결 사항 — 삽입·이동 위치 표현과 Patch 적용 순서
