# Phase 1 테스트 영역 편집 방식

- 날짜 및 상태 — 2026-11-07, 확정
- 결정 — 사용자가 테스트 영역의 화면을 직접 편집한다.
- 이유 — 이유 미기록
- 검토한 선택지 — HTML 입력창과 미리보기, 화면 직접 편집
- 추가 결정 — 태그 추가는 미리 준비한 버튼을 사용한다. 이유 미기록.
- 검토한 선택지 — 미리 준비한 버튼, 태그 이름 직접 입력
- 추가 결정 — 새 요소는 사용자가 선택한 요소 바로 뒤에 추가한다. 이유 미기록.
- 미결 사항 — 선택된 요소가 없을 때의 동작, 버튼으로 제공할 태그 범위와 속성 편집 방법
