# Phase 2 할 일의 브라우저 저장

- 날짜: 2026-11-10
- 상태: 사용자 선택
- 결정: 할 일 목록과 완료 상태를 브라우저에 저장하여 새로고침 후에도 유지한다. localStorage로 구현하는 설계를 적용한다.
- 이유: 새로고침 후에도 할 일과 완료 상태를 유지한다는 설명이 포함된 선택지를 사용자가 선택했다. 별도의 이유는 미기록.
- 대안: 메모리에서만 관리하여 새로고침 시 초기화.
- 범위: 같은 브라우저·같은 origin의 저장이며 서버·다른 기기 동기화는 포함하지 않는다. 추가 사용자 선택으로 draft·filter는 저장하지 않는다. 새로고침과 앱 재시작 시 draft는 빈 값, filter는 전체로 시작한다.
- 기존 초안의 저장소 영속화 제외 제안은 이 결정으로 대체한다.

## 추가 선택 — 저장 범위

- 사용자는 “할 일·완료 상태만 저장 — 입력창은 비우고 필터는 전체로 시작”을 선택했다.
- 이유: 이유 미기록.
- 기존 미확정 기록을 대체하며, 전체 작업 화면까지 복원하는 대안은 채택하지 않았다.
