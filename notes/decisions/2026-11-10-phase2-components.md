# Phase 2 컴포넌트의 역할별 분할

- 날짜: 2026-11-10
- 상태: 사용자 선택
- 결정: 루트 App 아래에 입력·추가, 필터, 목록, 개별 항목, 개수 요약을 담당하는 5종의 자식 컴포넌트를 둔다. 개별 항목 컴포넌트는 목록 안에서 반복 사용한다.
- 과제 제약: 모든 State·Hook은 App에서 관리하며 자식은 props만 사용하는 순수 함수다.
- 이유: props 전달과 UI 역할을 설명하기 좋다는 설명이 포함된 선택지를 사용자가 선택했다. 별도의 이유는 미기록.
- 대안: 입력창·목록 중심으로 크게 묶고 나머지는 App에서 작성.
- 범위: 역할 분할을 확정했다. 함수·파일·props의 구체적 이름은 구현 제안이다.
