# Phase 2 컴포넌트 작성 문법: JSX

- 날짜: 2026-11-10
- 상태: 사용자 선택
- 결정: Phase 2 컴포넌트의 UI는 JSX로 작성하고 빌드 시 자체 VDOM 생성 함수 호출로 변환한다. React 런타임을 사용하지 않는다.
- 이유: HTML과 비슷하게 작성하고 빌드 시 함수 호출로 변환한다는 설명이 포함된 선택지를 사용자가 선택했다. 별도의 이유는 미기록.
- 대안: h() 함수를 코드에서 직접 호출하는 일반 JavaScript 작성 방식.
- 범위: JSX 사용을 확정했다. 세부 props 변환 규칙과 빌드 설정은 설계·구현 제안으로 남긴다. 이전 초안의 직접 h() 호출 제안은 이 결정으로 대체한다.
