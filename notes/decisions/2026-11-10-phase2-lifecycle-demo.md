# Phase 2 앱 종료·다시 시작 시연 버튼

- 날짜: 2026-11-10
- 상태: 사용자 선택
- 결정: 앱 외부에 종료·다시 시작 제어 버튼을 제공한다. 종료는 unmount와 Effect 정리·제목 복원을 실행하며, 다시 시작은 저장된 할 일을 읽어 새 인스턴스를 mount한다. 종료로 저장 데이터를 삭제하지 않는다.
- 이유: mount·unmount와 제목 복원을 직접 확인한다는 설명이 포함된 선택지를 사용자가 선택했다. 별도의 이유는 미기록.
- 대안: 할 일 UI만 제공하고 종료·정리를 자동 테스트로 검증.
- 범위: 생명주기 시연 제어 제공을 확정했다. 버튼의 세부 배치·스타일은 구현 시 정한다.
