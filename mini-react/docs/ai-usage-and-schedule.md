# AI 활용 방식 (2주 실험) + 1주차 개인 스케줄 초안

## 1. AI 활용 방식 제안

### 역할 나누기
| 사람이 하는 일 | AI가 하는 일 |
|---|---|
| 요구사항 해석 (애매한 문장 결정) | 구현 코드 작성 |
| 설계: 데이터 약속, 불변식 | 테스트 코드 작성 (기대값은 사람이 줌) |
| 예측: 테스트 기대값을 먼저 적기 | 설명 초안, 그림, 시각화 페이지 |
| 판정: 예측과 실제를 비교하고, 핵심 줄 설명 | 엣지 케이스로 내 코드 공격하기 |

### 상황별 사용법 4가지
1. **개념 학습: AI가 묻고 내가 답한다**
   - AI가 질문을 작게 쪼개서 묻게 한다. 막히면 "더 작게"라고 한다.
   - 이해가 안 되면 형식을 바꾼다 (글 → 그림 → 실험 페이지).
2. **구현: 함수 하나씩**
   - 작은 입력 → 기대 출력을 내가 먼저 적는다 (예측).
   - AI가 구현한다.
   - 실행해서 예측과 비교한다. 틀린 곳이 배울 곳이다.
3. **검증: AI를 레드팀으로**
   - "이 diff를 깨뜨리는 입력을 5개 만들어 줘" → 테스트에 추가한다.
4. **공유: ✅ / ❔ 표시**
   - AI 초안도 통째로 공유해도 된다. 다만 ✅(내가 설명 가능) / ❔(AI 초안, 미확인)을 표시한다.
   - 결정은 이해한 사람이 1명 이상 있는 것만 한다.

### 매일 기록 (3줄)
```
상황:  무엇을 하려고 했나
방식:  AI를 어떻게 썼나
결과:  잘 됐나 / 안 됐나 → 다음엔 어떻게
```

### 1일차(11/6) 기록 예시 (실제로 겪은 것)
- 긴 초안을 통째로 받음 → 내가 설명하지 못함 → ✅/❔ 표시 규칙을 만듦
- 웹 페이지를 읽기만 함 → 다음 날 잊음 → 백지에서 다시 떠올리기로 바꿈
- 질문을 작게 쪼개서 받음 → 한 단계씩 풀림 (path, patch 타입 5가지)
- 비유(메모/진짜)는 혼자 이해할 때 좋았음 → 팀 공유는 정확한 용어로
