# Phase 2 지도 — useState까지 (한 장)

> 읽고 나서 각 줄에 ✅(내 말로 설명 가능) / ❔(모르겠음)를 붙인다. ❔가 다음에 볼 곳.

## 1. 한 줄
**버튼을 누르면 → 상태를 바꾸고 → 다시 그린다.** 다시 그리기는 Phase 1 블록(diff → applyPatches)을 그대로 쓴다.

## 2. 그림
```
버튼 클릭
 → setCount(새 값)          ① 상자의 칸 값을 바꾸고  ② app.update()를 부른다
 → update()
     → Counter() 다시 실행   (안에서 useState가 칸에서 지금 값을 읽음)
     → 새 VNode
     → diff(이전, 새) → 지시서 → applyPatches → DOM 첨삭
     → 이전 = 새 (저장)
 → 브라우저가 화면을 다시 그림 (우리 코드 밖)
```

## 3. 등장인물 4개
| 이름 | 한 줄 | 계단 |
|---|---|---|
| Counter() | 상태를 읽어 VNode(설계도)를 만들어 돌려주는 함수. 화면은 안 건드림 | 3 (view) |
| FunctionComponent | Counter를 감싸고 오래 살아 있는 상자 (C 구조체). 속성: fn, container, oldVNode, hooks | 4 |
| setCount | **바꾼다**: 칸 값 바꾸기 + 다시 그리기 | 5-2 (직접 씀) |
| useState | **읽는다**: [지금 값, setCount]를 돌려주는 갈고리(Hook) | 5-2, 5-3 |

## 4. 오늘 깨진 예측 3개 (= 배운 것)
| 예측 | 실제 | 배운 것 |
|---|---|---|
| `a`는 5 | 0 | 꺼낸 값은 사진. 새 값은 다시 불러야 (= update가 Counter를 다시 부름) |
| hookIndex는 이어서 센다 | 칸 2, 3으로 늘어남, 화면 0 | hookIndex는 "이번 그리기에서 몇 번째"인 임시 번호 → 매번 0부터 |
| draw()에 저장 없어도 됨 | -1 누르면 화면 안 바뀜 | 다시 그린 뒤 이전 = 새로 저장해야 다음 비교가 맞다 |
