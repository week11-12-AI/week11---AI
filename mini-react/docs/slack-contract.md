# 슬랙 글 ① 구현 전 합의 (용어 4개 + 맞출 것 2개)

구현 전에 1분만! 용어 4개 + 맞출 것 2개예요.

📖 용어 (이 뜻으로 같이 써요)
• DOM: 브라우저가 화면에 실제로 그리는 태그 트리 (진짜)
• VNode: DOM을 베낀 JS 객체. 수정 전/후를 비교하려고 씀 (메모)
• diff: 이전·새 VNode를 비교해서 수정 지시서를 쓰는 함수
• patch: 지시서대로 실제 DOM을 고치는 유일한 함수

🤝 맞출 것 2개 (함수 안은 각자 자유, 함수 사이를 오가는 데이터만)
① VNode (diff에 들어가는 것)
  { type: "p", props: { class: "a" }, children: ["안녕"] }
  - type = 태그 이름 / 속성 없으면 props: {} / 글자는 children 안에 문자열로
② 수정 지시서 (diff에서 나오는 것)
  [ { op: "TEXT", path: [0, 0], value: "4" } ]
  - op = 할 일: CREATE / REMOVE / REPLACE / PROPS / TEXT
    (VNode의 type과 헷갈리지 않게 op로 이름을 나눴어요)
  - path = 루트에서 몇 번째 자식으로 내려가는지 ([0,0] = 첫 자식의 첫 자식)

⚠️ 약속 하나: patch 후에는 새 VNode를 "이전 VNode"로 저장해야 해요.
   (이전 VNode ≠ 현재 DOM이면 diff가 틀린 지시서를 써요. 예: 목록에 B가 두 번 붙음)

왜 맞추나? merge할 때 서로의 diff·patch를 바꿔 끼우려면 이름이 같아야 해서요.
