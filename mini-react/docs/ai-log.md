## 자주 쓰는 요청
- "더 작게" — 질문이나 설명이 크면
- "한 번에 이해 안 돼" — AI가 설명 크기를 줄인다
- "이 함수를 깨뜨리는 입력 5개" — 레드팀 (검증 단계)
- "이거 나중에 바꾸기 쉬워?" — 가설 1

## 날짜별 3줄 (상황 / 방식 / 결과 → 다음엔)
### 11/6 (금)
- 긴 초안을 통째로 받음 → 설명 못 함 → ✅/❔ 표시 규칙을 만듦
- 웹 페이지를 읽기만 함 → 다음 날 잊음 → 백지에서 떠올리기로 바꿈

### 11/7 (토)
- 상황: 공백 글자 규칙을 정해야 했는데 판단할 경험이 없었다
- 방식: 판단에 필요한 정보 + 제안을 달라고 했고, 이해가 안 돼 "한 번에 이해 안 돼"라고 말했다
- 결과: 표와 예시로 줄어든 설명을 받고 직접 정함 → 다음엔 처음부터 "작게"라고 요청

### 11/9 (월)
- 상황: domToVNode 예측
- 방식: 빈칸을 하나씩 받아서 채움 ("더 작게")
- 결과: 틀린 곳 2개(쉼표, children 목록) → 틀린 곳에서 이유를 배움
